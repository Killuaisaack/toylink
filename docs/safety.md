# 安全与隐私

1. 用户始终拥有最终控制权；角色授权默认关闭且不持久化。
2. 所有运行请求共享同一套校验、用户上限、代码上限、确认和停止逻辑。
3. 新动作替换旧动作前先停止；断开、设备移除、聊天切换和异常都会触发停止。
4. “立即停止”固定放在 SillyTavern 魔法棒下拉菜单中，停止调用可以重复执行。
5. 如果浏览器无法确认停止，界面要求用户立即使用设备自身的停止方式。
6. 模型不会获得连接地址、设备名称或编号、蓝牙配置、原始字节和底层错误。
7. 不上传聊天、设备流量或使用统计；不使用第三方 CDN。
8. 不包含隐蔽、后台、无人值守或未经同意的远程控制功能。

ToyLink 是通用输入与传输实现，不保证特定设备兼容。用户负责确认其蓝牙配置来源与用途合法。
