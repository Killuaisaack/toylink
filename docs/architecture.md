# ToyLink 架构

ToyLink v0.1 是浏览器端 SillyTavern 扩展，由以下边界组成：

- **SillyTavern 适配层**：读取扩展设置、监听聊天变化、注册函数工具，并把基础控制放进魔法棒扩展菜单；完整配置只在用户主动打开时以弹层显示。
- **ToyLinkCoordinator**：维护当前连接、明确设备选择、会话授权、命令去重、确认、定时停止和看门狗。
- **连接模块**：Intiface 与用户自备蓝牙配置分别封装底层对象，只向核心暴露统一接口和经过整理的事件。
- **蓝牙配置编解码器**：纯函数式校验和字节生成，不访问浏览器或网络。
- **界面层**：只通过 Coordinator 和设置回调操作，不直接控制设备。

所有非停止命令必须经过同一个 Coordinator。连接模块不能绕过安全上限；模型不能选择设备、修改地址、修改安全上限或提供原始蓝牙字节。

浏览器页面是执行边界。SillyTavern 在 VPS 上运行时，Intiface 和 Web Bluetooth 仍然位于访问页面的手机或电脑附近。
