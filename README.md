# ToyLink v0.1

ToyLink 是一个面向成年用户的 SillyTavern 第三方扩展。只有在用户明确授权后，它才允许角色在本地安全上限内请求个人持有的兼容触觉设备运行。

> **重要提示**：ToyLink 不能替代设备自身的安全措施。第一次测试时请保持低强度、短时间，并确保可以立即使用设备本身的停止方式。

## 能做什么

- 通过 **Intiface Central / Buttplug** 连接已受支持的设备。
- 使用你自己合法持有的声明式蓝牙配置，通过浏览器直接连接设备。
- 在不使用模型的情况下进行低强度手动测试。
- 在当前 SillyTavern 支持函数工具时，让角色请求“运行”“停止”和“查看粗略状态”。
- 通过始终可见的“立即停止”按钮、本地定时停止和独立看门狗保护用户控制权。

ToyLink v0.1 只支持单个已选择设备的振动与停止。不支持旋转、伸缩、多设备、复杂模式、厂商云服务、远程中转或协议逆向。

## 安装

1. 将本仓库发布到一个 SillyTavern 可以访问的 Git 仓库。
2. 在 SillyTavern 中打开 **扩展 → 安装扩展**。
3. 粘贴仓库的 Git 地址并安装。
4. 刷新页面，点击聊天界面底部的魔法棒，在扩展下拉菜单中使用 ToyLink 基础控制；需要编辑蓝牙配置时，点击“打开完整设置”。

仓库已包含 `dist/index.js` 和 `dist/style.css`，普通使用者不需要运行 `npm install` 或构建命令。

## 本地连接是什么意思

SillyTavern 可以运行在 VPS 上，但 ToyLink 的设备连接代码运行在打开页面的手机或电脑浏览器中：

```text
VPS 上的 SillyTavern
        │ 提供扩展文件
        ▼
用户的手机/电脑浏览器（ToyLink 与安全控制）
        │ 本地 WebSocket 或 Web Bluetooth
        ▼
Intiface Central / 蓝牙设备
```

默认地址 `ws://127.0.0.1:12345` 中的 `127.0.0.1` 指的是**正在打开 SillyTavern 页面的手机或电脑**，不是 VPS。

## 使用 Intiface

1. 在设备附近的电脑上安装并打开 Intiface Central。
2. 在 ToyLink 中选择“通过 Intiface 连接”。
3. 默认地址为 `ws://127.0.0.1:12345`；如你修改过 Intiface 设置，可在界面中填写自己的 `ws://` 或 `wss://` 地址。
4. 点击“连接 Intiface”，再开始查找设备。
5. 从列表中选择设备并点击“使用这个设备”。
6. 先进行一次低强度测试，再决定是否允许角色控制。

ToyLink 不会声称所有设备都兼容。设备是否可用取决于当前 Intiface/Buttplug 支持情况和你的实际环境。

### HTTPS 与 WebSocket

如果 SillyTavern 页面使用 HTTPS，浏览器通常会拦截不安全的 `ws://` 连接。ToyLink 不会关闭 TLS 检查，也不会通过公共代理绕过限制。请根据自己的可信网络环境配置安全的连接方式。

非本机地址会在连接前再次询问，以避免误连到不受信任的位置。

## 使用自己的蓝牙配置

1. 使用你合法持有且确认可以使用的设备 UUID 与指令字节准备 JSON 文件。
2. 在 ToyLink 中选择“使用自己的蓝牙配置”。
3. 粘贴 JSON 或从本地文件导入。
4. 点击“检查并保存”。
5. 点击“启用蓝牙配置”，再点击“开始查找”打开系统设备选择窗口。
6. 在 ToyLink 列表中再次点击“使用这个设备”。
7. 第一次低强度测试前核对界面显示的最终设备指令。

蓝牙配置只是数据，不能包含 JavaScript、表达式、网址、回调或下载内容。ToyLink 不提供设备逆向、抓包、APK 分析或厂商协议库。格式详情见 [`docs/ble-profile.md`](docs/ble-profile.md)。

### 浏览器限制

- Web Bluetooth 只在部分浏览器和安全上下文中可用。
- 系统设备选择窗口必须由用户点击打开。
- 网页不能强制关闭已经弹出的系统选择窗口；点击“停止查找”后可能仍需手动关闭。
- 写入成功只表示浏览器完成了写入请求，不等于设备一定产生了预期动作。

## 角色控制与确认

- 角色控制每次启动都为关闭状态，不会保存。
- 切换聊天或角色、断开设备、更换连接方式或设备时会关闭角色控制并尝试停止。
- “每次运行前都询问我”默认开启。关闭后，该偏好会保存，但安全上限和立即停止仍然有效。
- `toy_stop` 是安全操作，即使角色控制没有开启也允许执行。
- 模型只能收到粗略状态，不会获得地址、设备名称或编号、蓝牙配置及原始字节。

## 固定安全限制

- 代码级最高强度：70%。
- 代码级最长时间：10 秒。
- 默认用户上限：35% / 3 秒。
- 手动测试最高：20% / 1 秒，默认 10% / 0.5 秒。
- 每次运行都有浏览器本地停止定时器和独立看门狗。

如“立即停止”显示无法确认停止，请马上使用设备自身的停止方式，并关闭 Intiface 或蓝牙连接。

## 隐私

ToyLink 不向无关服务发送聊天内容、设备标识、蓝牙流量或使用统计。它只在 SillyTavern 扩展设置中保存：

- 选择的连接方式；
- 用户填写的 Intiface 地址；
- 已通过格式校验的蓝牙配置；
- 用户安全上限、确认偏好和界面偏好。

角色授权、活动动作、连接声明、设备对象和临时设备编号只存在于当前页面内存中。

## 常见问题

### 列表中没有设备

确认 Intiface Central 已经启动并正在查找；或确认蓝牙配置中的设备名称开头与系统选择窗口中设备名称一致。ToyLink 只显示声明具有振动能力的 Intiface 设备。

### HTTPS 页面无法连接 `ws://127.0.0.1`

这是浏览器的混合内容安全限制。ToyLink 不会绕过它。需要在你的可信环境中为本地连接配置合适的安全访问方式。

### 当前浏览器不支持蓝牙

改用支持 Web Bluetooth 的浏览器和系统，或选择 Intiface 连接。手动导入、检查和导出蓝牙配置仍可使用。

### 角色没有调用设备

确认当前 SillyTavern/模型支持函数工具、已经选择设备，并在本次聊天中打开“允许当前角色请求设备运行”。

## 开发与验证

需要 Node.js 22 或兼容版本。

```powershell
npm ci
npm run typecheck
npm run lint
npm run test:unit
npm run test:integration
npm run build
npm run verify
```

构建产物必须随仓库提交，以满足 Git URL 直接安装。测试说明见 [`docs/testing.md`](docs/testing.md)。

## 实机声明

当前仓库的自动化测试使用模拟连接、合成配置和虚拟时钟。只有在 [`docs/intiface-hardware-validation.md`](docs/intiface-hardware-validation.md) 填写完整环境并完成停止测试后，才能声明某个具体设备已通过实机验证。
